## Progressive reading
Begin with sparkle-auto-landing-director and only the current phase. Use SKILLS-INDEX
for targeted paths; open source workflows and their templates when selected. Full content
is installed, not stuffed into AGENTS or read on every turn. Sources may contain broad
workflows; a small change does not require 41 workflows, three rebrands or a generation batch.
One source of truth per decision. Integrate into established project docs when they exist.
Do not create all optional templates, protocols and reports for a trivial task.

## Asset and motion essentials
CODE = native UI, copy, CTA, layouts, simple diagrams; REAL = authentic logo, screens
and approved evidence; GENERATE = meaningful custom art; REUSE suitable assets; OMIT
clutter. Generated proof is not real UI. Missing assets block only dependent work.
After an explicit build request, use available image generation where justified, with a
needed calibration asset and real inspection. Installation cannot enable tools or budgets.
Use one ScrollStory for 5+7 chapters, two major story sections at most by default, normal
scrolling, direct navigation and mobile/reduced-motion linear alternatives. Twelve video
keys are slots, not twelve existing files. No autoplay sound or non-working public Play.

## Current capability versus source memory

and library details with current official docs during execution. No global skill changes,
