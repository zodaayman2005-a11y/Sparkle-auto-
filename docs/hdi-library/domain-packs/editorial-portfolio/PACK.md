# Domain Pack — Editorial and Portfolio

## Primary outcome

Present ideas, work, or authorship with memorable hierarchy and pacing while preserving readability, navigation, and accessible access to the content.

## Dominant priorities

- Typography and editorial voice.
- Project or story hierarchy.
- Image sequencing and crop.
- Rhythm and controlled asymmetry.
- Authorship and distinctiveness.
- Reading comfort.
- Archive/discovery.
- Mobile recomposition.

## Composition

- Use type and image as visual masses.
- Define stable anchors before asymmetry.
- Vary density and scale to create pacing.
- Use intentional overlaps and breakouts.
- Keep metadata and navigation findable.
- Separate project identity from site identity.

## Case studies

A strong case study usually clarifies:

- Context and problem.
- Role and constraints.
- Approach or concept.
- Important decisions.
- Process evidence.
- Final outcome.
- Measurable result when truthful.

Do not present only beautiful full-bleed images without explanation if the goal is professional evaluation.

## Typography

- Test long titles and multiple scripts.
- Keep body measure readable.
- Use experimental type as an enhancement, not the only access to meaning.
- Maintain semantic heading order.

## Motion

- Support pacing, image transitions, and project continuity.
- Avoid making navigation or reading depend on a custom cursor or precise pointer movement.
- Provide reduced-motion alternatives.

## Common failures

- Experimental composition with no reading path.
- Every project using the same template despite different stories.
- Tiny body copy.
- Custom cursor blocking basic interaction.
- Project images without context or alt strategy.
- Mobile becoming a featureless vertical image dump.

## Recommended skill order

`design-director` → `reference-intelligence` → `visual-composition` → `typography-content` → `color-imagery` → `ux-architecture` → `motion-interaction` → `responsive-rtl` → `design-to-code` → `visual-qa-refinement`

## Additional hard gates

- [ ] Reading order is clear without relying on visual position only.
- [ ] Body content remains readable across widths.
- [ ] Every project has meaningful context and navigation.
- [ ] Experimental interaction has a conventional accessible path.
- [ ] Images have appropriate descriptions or decorative treatment.
