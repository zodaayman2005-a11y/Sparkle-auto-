# Design Memory

Memory should store decisions and preference evidence, not blindly apply one favorite style to every brand.

## Layers

- Global preferences: stable choices the user repeatedly makes.
- Brand preferences: identity and rules unique to one brand.
- Project decisions: choices locked for one current project.
- Rejected patterns: patterns and the contexts in which they failed.

Record reasons. “User chose A” is less useful than “User chose A because Arabic hierarchy was stronger and the product proof was larger.”
