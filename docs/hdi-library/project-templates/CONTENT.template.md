## Interface writing

### Buttons

- Use verbs that describe the immediate result.
- Do not use “Submit” when a more specific action exists.

### Errors

- State what happened.
- Explain what the user can do next.
- Do not blame the user.

### Empty states

- Explain the state.
- Provide the next useful action.
- Do not fill empty states with decoration alone.

### Loading and success

- Use progress language only when progress is real.
- Confirm the completed outcome, not merely the click.
