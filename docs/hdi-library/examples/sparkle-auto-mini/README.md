# Sparkle Auto Mini Example

This is a compact demonstration of how HDI-OS truth files work together for a real bilingual service-business SaaS. It is intentionally smaller than the full Sparkle Auto production master plan and must not replace that project’s complete approved source of truth.

## Demonstrated decisions

- Arabic-first and mobile-first service-business positioning.
- Product truth separated from visual identity.
- Fresh Blue Neo-Brutalist direction without dark, generic brutalism.
- Real product screenshots only.
- One message and one focal contract per section.
- Direction-aware Arabic/English composition.
- Character and palette locks.
- Quality gates before implementation is approved.
