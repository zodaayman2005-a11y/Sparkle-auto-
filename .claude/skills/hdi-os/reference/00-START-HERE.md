# HDI-OS v1.2.0 — Clean Multi-Markdown Edition

This edition splits the single-file HDI master into logically organized Markdown files.

## What is inside

- **34** one-file-per-skill documents.
- **9** separate domain-pack documents.
- Research, prompts, QA, templates, orchestration, references, docs, integrations, and tooling grouped separately.
- No duplicate SOURCE mirror.
- Designed to be easier to upload, browse, or copy into a Codex project.

## Read order

1. `00-CODEX-SETUP.md`
2. `01-CORE/core.md`
3. Relevant files from `02-SKILLS/`
4. Relevant domain file from `04-DOMAIN-PACKS/`
5. Add research / QA / prompts only when the current task needs them.

## Important

Do **not** ask Codex to read every file on every turn.
Use the router/design-director behavior and load only relevant skills.
