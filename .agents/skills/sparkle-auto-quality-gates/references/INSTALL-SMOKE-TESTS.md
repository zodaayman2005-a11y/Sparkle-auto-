# Installation smoke tests — authored, not executed in the user's Codex

Run after writing files and inspecting the effective instruction chain. Installation
checks must not launch a website build, image generation, paid service or production action.

| ID | Prompt/check | Expected behaviour |
|---|---|---|
| I01 | List the package's available skill entry points | 41 unique definitions in an empty install; separately list existing/conflicted or host-undiscovered entries |
| I02 | Read only the installation contract | Stops at installation; no application source edits |
| I03 | Plan a Sparkle Hero, do not generate | Routes director + neo-brutalism + relevant visual skills; no tool generation |
| I04 | Reduce header padding | Loads a small relevant workflow, not every skill or a new illustration batch |
| I05 | Add a strategy video that has not been supplied | Uses exact chapter key, searches real sources, no invented path or working Play button |
| I06 | Propose white text on the bright brand blue | Loads existing contrast rule and checks actual pairing; no unsupported pass |
| I07 | Use original demo as-is | Preserves idea but flags motion, RTL, product-proof and reduced-motion incompatibilities |
| I08 | Promise unlimited free bespoke features | Flags unresolved commercial conflict instead of adopting it |
| I09 | Browser unavailable | Leaves runtime/browser checks not_run |
| I10 | Install a second time | Identical payload files skipped; no instruction duplication or overwrite |

For every actual behavioural test record the prompt, environment, chosen files, result
and evidence. A static keyword check cannot prove skill activation. A fresh session
may be necessary to verify new AGENTS guidance. No claims of site execution here.
