# Sparkle Auto — Landing Director
Package-authored router derived from the supplied landing plan, not an original HDI skill.

## Start
Read applicable AGENTS guidance and `docs/sparkle-skills/PROJECT-CONTRACT.md`.
Read `docs/sparkle-skills/SKILLS-INDEX.md` and `references/PHASE-ROUTING.md` selectively.
The complete plan and original content are in
`docs/sparkle-skills/sources/SPARKLE-AUTO-NEO-BRUTALISM-CODEX-MASTER-PLAN.md`.
The newest maintained project facts may supersede a draft; record actual conflicts.

## Task router
Installation only → verify files, safe routing integration and structural checks; stop.
Planning only → define tasks/assets without generating or modifying the application.
Authorized implementation → inspect and reuse the existing application and prior work.
A small correction → load only that specialist; do not restart the entire programme.

## One owner per decision
This router owns scope and stage progression. design-director assists with design
decisions; hdi-web-visual-art-director owns asset production; motion-interaction and
sparkle-auto-scroll-video share one scroll contract; visual-qa-refinement reviews
actual output. They are cooperating responsibilities, not parallel competing plans.
Do not load all 41 full skills on each turn. Use the index to open a needed path
even when the host's initial skills list is shortened. Record actual skill use only.

## Four always-relevant execution contracts
`sparkle-auto-neo-brutalism` → art, tokens, typography and composition.
`sparkle-auto-scroll-video` → 5+7 chapters, native scrolling and media behaviour.
`sparkle-auto-bilingual-conversion` → content, locale, commercial truth and forms.
`sparkle-auto-quality-gates` → actual evidence and honest delivery.
Load each when that part of the work starts, not as four full up-front documents.

## Build order after a separate implementation request
Follow G00–G07 in PHASE-ROUTING. Existing G02/NB labels may belong to earlier work:
retain the project's established tracker and map labels; do not discard completed code.
Stabilize a representative hero, strategy view and product view before multiplying
components. Stabilize the scroll/video engine before filling all twelve chapters.
English is architected from the beginning, even when complete locale QA is in G06.

## Close each authorized stage
State changed files, actual skills used, tests executed, screenshots inspected,
assets produced/reused, missing evidence and the next independent task.
Do not publish, add a new paid service, change commercial policy or send production
customer data merely because installation or local implementation was authorized.
